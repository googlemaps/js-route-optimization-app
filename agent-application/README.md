# Route Optimization Agent Application

A web application that allows users to interact with [**Google Maps Platform Route Optimization**](https://developers.google.com/maps/documentation/route-optimization) (GMPRO) through natural language conversations. Users can ask questions about route optimization, generate requests, solve routes, and visualize the results on an interactive map.

## Intended Use

This application is intended as an exploratory tool for learning about and experimenting with the Route Optimization API. It should not be deployed in any production critical path. Customers should implement their own solutions to integrate Route Optimization into their business processes.

## Deployment

Pre-configured Terraform is provided for ease of deployment. See [infrastructure/README.md](infrastructure/README.md) for detailed instructions on setting up your Google Cloud environment.

The application is served as a single Docker container containing a FastAPI backend that serves a statically generated Angular frontend. For convenience, a [build script](build.sh) has been provided to build the container, tag it, and deploy to Artifact Registry. To run it:

```bash
export REGISTRY=us-central1-docker.pkg.dev/your-project/application-registry/application
./build.sh
```
